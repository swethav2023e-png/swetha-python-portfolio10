# Swetha V — Advanced Python Programming Portfolio

A responsive static portfolio website built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser.

## Deploy
Import this folder into Vercel as a static site, or deploy the repository with the root directory set to this folder. No build command is required.
